# SaaS AI Chatbot

A production-grade AI chatbot that allows users to upload documents and chat with them.

## Tech Stack
- FastAPI (backend)
- React (frontend)
- PostgreSQL (database)
- ChromaDB (vector database)
- AWS S3 (file storage)
- Docker (containerization)

## Setup
1. Clone the repo
2. Copy .env.example to .env and fill in values
3. Run docker-compose up

## Environment Variables
See .env.example for required variables
